## How to Use This Document

1. **When a bug is found:** Add an entry to the table below with full details.
2. **When a bug is fixed:** Update `Status` to ✅ Fixed and add the fix description + date.
3. **Severity levels:** 🔴 Critical · 🟠 High · 🟡 Medium · 🟢 Low
4. **Status values:** 🐛 Open · 🔄 In Progress · ✅ Fixed · ❌ Won't Fix (with reason)
